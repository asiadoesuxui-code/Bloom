Place 16:9 floral photographs as `*.png` in this folder (or in `src/source/` if you prefer that name). Each Generate picks one image at random. You can add, remove, or replace files anytime — nothing is registered in code.

`npm run dev` shrinks photos wider than 960px and keeps the landscape mosaic's cell colours. Restart the dev server (or run a fresh build) after changing files so Vite rescans the folder.
